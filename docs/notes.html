서버오라클 클라우드싱가포르. Python 서버가 수집·계산·저장, 정해진 시간에 자동 갱신
앱웹앱Next.js 화면을 서버가 함께 띄움. 태블릿·휴대폰 같은 화면, 같은 데이터
증권사키움 REST API장중 실시간 시세, 모의투자 계좌로 자동 주문. 실전 주문은 막아 둠
나Tailscale 접속개인 VPN 주소 + 웹 비밀번호. 바깥에서는 보이지 않음

코드는 GitHub 비공개 저장소에 있고, 고친 내용을 올리면 서버가 15분마다 받아서 반영합니다. 전략·모투·매매일지·자동 매매 기록은 서버의 작은 데이터베이스(SQLite)에, 주가는 파일(parquet)로 저장합니다. 키움 키는 서버 파일(권한 600)에만 있고 화면에는 끝 4자리만 보입니다.
